- A key advantage of a Linear Regression model is that it is easy to interpret the coefficients/weights b0, b1, …, bk.

Every 1 degree warmer => 6.38 more bike rentals per hour Every 1 unit increase in humidity => 2.79 fewer bike rentals per hour

- However, it turns out that when you have variables that are too highly correlated, the coefficients/weights become more difficult to interpret.

-  LR is a team effort. A good regression model should have independent variables that work well together, not just individually predict well.
- An ideal next variable brings “something new to the table”
- Part of the value of the linear regression model comes from the fact that we can easily see each player’s contribution to the prediction (i.e., the coefficient).
- When two players on the team are too similar to each other, we cannot tease apart their contributions.

## Page 51

Summary: detecting irrelevant variables

- Irrelevant variables are harmful to a linear regression model because they impair interpretability and may reduce predictive power

- We can detect irrelevant variable by looking at the confidence interval of the coefficient estimates. o If the interval contains 0, the variable is insignificant/irrelevant o If the interval doesn’t contain 0, the variable is significant/relevant

- When we detect an irrelevant variable, it is best practice to simply remove it from the model.

## Page 70

The remedy: Out-of-Sample Testing

1. Partition your data set randomly (or, in some cases, chronologically) into a: o training set (~70% of observations), and a o test set (~30% of observations)  This is a proxy for future data! before creating any models

2. Generate a set of models (e.g., models with different sets of independent variables) using only the training data

3. Evaluate the predictive quality of the models on the test set using metrics like RMSE or MAE (and other business metrics of your choice that capture important aspects of your problem).

Evaluating on the test set is called out-of-sample testing

A process to create good models

1. Remove variables that don’t make managerial sense from the dataset (e.g., random ID numbers, day of the month in the Bluebikes problem) 2. Drop independent variables that have a high correlation (i.e., collinear) with other independent variables. Between a pair of collinear variables, drop the variable that has lower absolute correlation with the dependent variable. 3. Split your dataset into train and test sets (e.g., 70-30 random split). 4. Build a sequence of models as follows:

a) Run the regression and produce a model.

b) Calculate the train-set and test-set RMSE (or MAE)

c) In the model output, check variables for significance

d) If every variable is significant, go to Step 5. Otherwise, pick one of the insignificant variables and remove it from the previous model and go to (a) (important: a categorical variable should be removed only if EVERY one of its associated variables is insignificant).

Summary: Using norm.cdf(c, mean, sd)

- norm.cdf(c, mean, sd) is a Python function that calculates the probability that a random variable whose distribution is Normal with mean ”mean” and standard deviation “sd” takes on a value less than c.

- 1 - norm.cdf(c, mean, sd) gives the probability that such a random variable takes on a value greater than c.
