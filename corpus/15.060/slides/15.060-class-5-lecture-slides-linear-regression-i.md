Why Linear and Logistic Regression?

- Linear and Logistic Regression are the two fundamental models of predictive modeling.

- By understanding these models, you understand the fundamentals of predictive models. More complex models are really the “same” deep down. How you evaluate models, train them, interpret them…etc. are applicable beyond linear regression.

In tabular data, variables fall into one of two types

Numeric Variable
- The value is a number and arithmetic (+, -, *, /) make sense
- Examples: o Revenue o Temperature o Age

Categorical Variable
- The value is a label for a group that doesn’t carry a quantitative meaning
- Examples: o Non-numeric: Gender, ethnicity o Zip code / area code o Binary variables: Is married

Note: Sometimes, a categorical variable may be encoded numerically with some ordering.
- 1 = Monday, 2 = Tuesday, …, 7 = Sunday
- 1 = January, 2 = February, …, 12 = December However, we still consider these categorical because it doesn’t make sense to do arithmetic. What is Sunday divided by 2? What is January times 7?

TLDR: What does the correlation between two variables represent?

- Imagine doing a scatter plot of the two variables.

- If the scatter plot is close to a line, the correlation will be close to ±1. If the scatter plot is spread out as a blob, the correlation will be close to zero.

- If the pattern of points goes up from the bottom left to the top right, the correlation will be positive. If it goes down from the top left to the bottom right, the correlation would be negative.

Aside: What is ”wet bulb” temperature (i.e., temp_wb)?

“Dry bulb temperature is what happens when we stick a thermometer out into the air and see what the ambient temperature is. Wet bulb temperature is what happens if we put the thermometer in a wet sock and then wave it around in the air. What that tells us is how much the temperature can drop due to evaporation.

We use this for two reasons:

1. It helps us determine what the relative humidity of the air is and how much more moisture can dissipate into the air, thus changing the temperature.

2. It is a good indication of how much you can cool off if you are sweating.”

- Matt Weinberg (MBA ‘28, Meds)

- In general, a categorical variable with k distinct values (e.g., 7 days for day_of_week) is represented as k – 1 numeric 0-1 variables.

## Page 93

Why does adding a new variable reduce SSR?

- Adding a new variable reduces SSR because it gives a model more flexibility.

Rentals = b0 + b1 * Temperature

Rentals = b0 + b1 * Temperature + b2 * Humidity

- The model has the flexibility to use Humidity to improve its SSR. It can always choose to set b2 = 0, if Humidity is not useful! However, the added flexibility of having humidity cannot hurt!

## Page 94

Summary

- Predictive models are useful for:

o (1) Making decisions

o (2) Understanding the relationship between variables

- Linear regression is a predictive model that assumes the dependent variable is a weighted sum (linear combination) of the independent variables.

- A linear regression model is “fit” to a dataset by choosing coefficients that minimize the sum of squared residuals (SSR).

- R2 is an interpretable metric that measures the percent reduction in SSR from a baseline model that uses no independent variables.
