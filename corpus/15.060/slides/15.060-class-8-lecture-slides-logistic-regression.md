## Page 43

Logistic Regression Model: Summary

𝑧= 𝑏0 + 𝑏1 ⋅𝑋1 + 𝑏2 ⋅𝑋2 + … + 𝑏𝑘⋅𝑋𝑘

Pr 𝑌= 1 = 1 1 + 𝑒−𝑧

Intuition: Think of “z” like a score that is calculated by the weighted sum.

- The more positive z is → Higher probability of the Positive class
- The more negative z is → Lower probability of the Positive class
- z = 0 → 50% probability

## Page 44

How do we calculate the “best” values for the coefficients?

𝑧= 𝑏0 + 𝑏1 ⋅𝑋1 + 𝑏2 ⋅𝑋2 + … + 𝑏𝑘⋅𝑋𝑘

Pr 𝑌= 1 = 1 1 + 𝑒−𝑧

b0, b1, …, bk are chosen by the Logistic Regression algorithm* such that

- Probability (Y=1) will be high for those data points in the Positive class

- Probability (Y=1) will be low for those data points in the Negative class

*The details are beyond the scope of DMD. For those of you interested, it is called binary cross-entropy loss.

## Page 60

Interpreting the coefficients (summary)

Linear Regression
- bk is the change in Y corresponding to a 1 unit increase in xk.

Logistic Regression
- If bk is positive (negative), then a 1 unit increase in xk will increase (decrease) the probability Prob(Y=1)
- If bk > bj, then a 1 unit increase in xk will have a larger increase than a 1 unit increase in xj.
- However, the exact amount that the probability will increase (decrease) by cannot be inferred from bk

## Page 69

A “common sense” approach for Stage 2

- We will set a threshold* of 50%

- Classify as “Will Default” if probability of default for a data point is greater than the threshold

- Classify as  “Will Repay” if probability of default for a data point is less than or equal to threshold

We may refer to this as a “cutoff” as well
