Financial Accounting (15.515)

Self-Assessment Problem Set 2 - Solution

Balance Sheet Equation Approach: Assets = Liabilities + Shareholders' Equity

Approach: For each question, identify the accounts affected and trace the effect through the balance sheet equation. Revenue and expenses affect Shareholders' Equity through Net Income.

A. Billing and Revenue Recognition

Correct answer(s): 1, 2, 4

| Account / Effect | Assets | Liabilities | Shareholders' Equity |

| Accounts Receivable | + |  |  |

| Deferred Revenue |  | + |  |

The invoice can create Accounts Receivable even though the service has not yet been performed. The offset is Deferred Revenue, not Revenue. Thus Assets increase and Liabilities increase by the same amount, while Shareholders' Equity is unchanged. Sending an invoice does not by itself require revenue recognition.

B. Revenue Recognition and Cash Collection

Correct answer(s): 1, 2

Revenue recognition and cash collection do not have to occur at the same time. If revenue is recognized before collection, Accounts Receivable can increase along with Shareholders' Equity. If cash is collected first, Cash and Deferred Revenue increase; later, when the service is performed, Deferred Revenue decreases and Shareholders' Equity increases. Thus revenue recognition does not always increase Cash or Accounts Receivable on the recognition date.

C. Seller and Customer Accounting

Correct answer(s): 1, 2, 4

| Account / Effect | Assets | Liabilities | Shareholders' Equity |

| Seller: Cash | + |  |  |

| Seller: Deferred Revenue |  | + |  |

For the seller, receipt of the advance increases Cash and Deferred Revenue. Assets and Liabilities increase equally, so Shareholders' Equity is unchanged. For the customer, Cash decreases and an advance-payment asset can increase; total customer assets need not change. The seller has not yet earned revenue.

D. Product Sale

Correct answer(s): 1, 2, 3

| Account / Effect | Assets | Liabilities | Shareholders' Equity |

| Accounts Receivable | + selling price |  |  |

| Inventory | - cost |  |  |

| Revenue |  |  | + selling price |

| COGS |  |  | - cost |

Because control transfers at shipment, the seller recognizes Revenue and Accounts Receivable. It also removes Inventory and recognizes Cost of Goods Sold. The net increase in Shareholders' Equity is the gross profit (selling price minus cost). Accounts Receivable increases at selling price while Inventory decreases at cost, so those two amounts need not be equal.

E. Accounts Payable

Correct answer(s): 1, 2, 4

| Account / Effect | Assets | Liabilities | Shareholders' Equity |

| Purchase: Inventory | + |  |  |

| Purchase: Accounts Payable |  | + |  |

| Payment: Cash | - |  |  |

| Payment: Accounts Payable |  | - |  |

The purchase on account increases an Asset and a Liability by the same amount. The later payment decreases an Asset and a Liability by the same amount. Neither transaction by itself must affect Shareholders' Equity, and paying the supplier does not reduce expense in the period of payment.

F. Bad Debt Expense

Correct answer(s): 1, 2, 3

| Account / Effect | Assets | Liabilities | Shareholders' Equity |

| Allowance for Doubtful Accounts (contra-asset) | - |  |  |

| Bad Debt Expense |  |  | - |

Increasing the allowance reduces Net Accounts Receivable, so total Assets decrease. Bad Debt Expense reduces Net Income and therefore Shareholders' Equity by the same amount. Gross Accounts Receivable is unchanged because no specific customer balance has been written off.

G. Write-Off of an Account Receivable

Correct answer(s): 1, 2

| Account / Effect | Assets | Liabilities | Shareholders' Equity |

| Gross Accounts Receivable | - |  |  |

| Allowance for Doubtful Accounts | + to net A/R |  |  |

The write-off reduces Gross Accounts Receivable and reduces the Allowance for Doubtful Accounts. Because both the receivable and its contra-asset fall by the same amount, Net Accounts Receivable and total Assets are unchanged. There is no effect on Liabilities or Shareholders' Equity and no new Bad Debt Expense.

H. Allowance Reversal

Correct answer(s): 1, 2, 3

| Account / Effect | Assets | Liabilities | Shareholders' Equity |

| Allowance for Doubtful Accounts (contra-asset) | + to net A/R |  |  |

| Reversal of Bad Debt Expense |  |  | + |

Reducing the allowance increases Net Accounts Receivable and therefore Assets. Reversing previously recognized Bad Debt Expense increases Net Income and Shareholders' Equity by the same amount. Gross Accounts Receivable does not change.

I. Receivables Analysis

Correct answer(s): 1, 2, 3

This is primarily a ratio question rather than a new balance-sheet transaction. If Sales rise substantially while Gross Accounts Receivable remains nearly unchanged, Accounts Receivable turnover generally rises and days receivable generally falls. That pattern is consistent with faster collection. It does not necessarily establish anything about the aggressiveness of revenue recognition.

J. Deferred Revenue

Correct answer(s): 1, 2, 3

| Account / Effect | Assets | Liabilities | Shareholders' Equity |

| Customer advance: Cash | + |  |  |

| Customer advance: Deferred Revenue |  | + |  |

| Service performed: Deferred Revenue |  | - |  |

| Service performed: Revenue |  |  | + |

New customer advances increase both Cash and Deferred Revenue. When the company performs services that were previously deferred, the Liability decreases and Revenue increases Shareholders' Equity. The balance sheet equation remains in balance because Liabilities fall while Shareholders' Equity rises by the same amount. Recognizing some revenue does not require the ending Deferred Revenue balance to be zero.
