Question 4: One Line or Two? (10 points)

A new tech company runs a customer support center with two dedicated support agents. Agent A only handles Billing tickets, and Agent B only handles Technical tickets. Each agent was specifically trained for their own ticket type. Each agent resolves tickets at a rate of µ = 6 tickets per hour, regardless of type. On average, tickets are split evenly: 50% Billing, 50% Technical. The support center operates 10 hours per day.

Management is considering cross-training both agents so that either agent can resolve either ticket type. This would let tickets be handled by one shared queue feeding both agents (i.e., pooling), instead of two separate, parallel queues (one per ticket type), each currently receiving an average arrival rate of λ/2.
